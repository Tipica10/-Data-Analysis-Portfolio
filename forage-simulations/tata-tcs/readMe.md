Tata Data Visualisation — Forage Job Simulation
Problem / Objective

Simulated a real Tata Consultancy Services data analytics task: given a large retail transactional dataset, the goal was to clean and visualise the data to generate actionable business recommendations for a supply chain client.

Approach
Tools: Excel, Power Query, Power BI
Cleaned a retail dataset of 540,000+ rows — handling missing values, inconsistent formatting, and outliers
Used Power Query to transform and shape the data ahead of analysis
Built visualisations in Power BI to surface patterns in sales, returns, and stock movement
Translated the visual findings into business recommendations
