Survey Response Dashboard
Problem / Objective

Raw survey response data needed to be turned into an interactive dashboard that lets a non-technical viewer explore results — filter by respondent group, spot patterns, and drill into specific questions — without needing to read a spreadsheet.

Approach
Tools: Power BI, DAX, Power Query
Cleaned and reshaped raw survey export data using Power Query
Built custom DAX measures to calculate response rates, averages, and breakdowns by respondent group
Applied conditional formatting to highlight notable results (e.g. low-scoring areas) directly on the dashboard
Designed filters/slicers so the report is explorable rather than static
