Personal Investment Portfolio Analytics

Analysis of my own Stocks & Shares ISA (Trading 212) trading activity, combining a Python/pandas exploratory analysis with an interactive Power BI dashboard.

Overview

This project analyses 185 real personal trades totalling £2,250 of invested capital, exploring portfolio concentration, trading behaviour, and dividend income using both a notebook-based analysis and a dashboard for interactive exploration.

Tools & Tech
Python — pandas, matplotlib
Power BI — DAX, Power Query
Data source — Trading 212 transaction export (Excel)
