Client Churn Analysis (BCG Forage simulation)
Problem / Objective

Modelled on a BCG case-study format: given a merged client and pricing dataset, the goal was to explore the data and identify factors associated with customer churn.

Approach
Tools: Python, pandas, Jupyter Notebook
Merged separate client and pricing datasets into a single working dataframe
Cleaned and validated the merged data (types, missing values, duplicate checks)
Explored churn rates across client segments, pricing bands, and other available features
Visualised key relationships to surface which variables correlate most with churn
